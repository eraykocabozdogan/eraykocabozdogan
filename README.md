**Recent work**

- **Aegix** *(private)*: a local-first privacy layer for LLMs. It detects and
  tokenizes sensitive data with rules, regex and local SLMs before prompts reach
  remote models, then rehydrates responses locally. Includes a browser extension for
  ChatGPT/Gemini, a separate open relay, a Docker/GPU deployment and a golden-dataset
  evaluation harness.
- **Fu Enerji**: asset management, a CBC-based MILP technician scheduler (about 15%
  lower travel cost) and a FastAPI/PostgreSQL analytics module for a wind-farm
  operations platform.
- **Venn**: team lead of a Raspberry Pi telepresence robot with WebRTC audio/video,
  RTCDataChannel control and a React Native client (142 ms average video latency).
